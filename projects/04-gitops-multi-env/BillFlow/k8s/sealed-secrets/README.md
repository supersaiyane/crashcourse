# Sealed Secrets

This directory holds sealed secrets generated by `kubeseal`.

To generate a sealed secret:

```bash
kubectl create secret generic billflow-db-creds \
  --namespace=billflow-dev \
  --from-literal=DB_HOST=postgres.billflow-dev.svc \
  --from-literal=DB_USER=billflow \
  --from-literal=DB_PASSWORD=<your-password> \
  --from-literal=DB_NAME=billflow \
  --dry-run=client -o yaml | kubeseal --format yaml > dev-db-creds.yaml
```

Never commit plaintext secrets. Only commit the sealed (encrypted) versions.
