Infrastructure Stack

Packer
Hardened golden AMIs for EC2 instances
Vault
Dynamic database credentials, AppRole auth, SSH certs
OPA
Policy-as-code: require tags, restrict instance types, no public S3
Ansible
Post-provision config: monitoring agents, bootstrap playbooks
GitHub Actions
Terraform plan on PR, apply on merge, OIDC authentication
